# make-subset-font-css
```
USAGE:
  make-subset-font-css <path-to-utf8-file> <path-to-css-file>

  Prints to standard output the result of replacing each

    @font-face {
      <...>
      src : url(<path-to-ttf-file>);
      <...>
    }

  in the css-file with 

    @font-face {
      <...>
      src : url(data:font/ttf;base64,<subset-font>) format('truetype');
      <...>
    }

  where <subset-font> is the base64-encoding of the subset-font
  generated by fonttools from the ttf-file, restricted to the unicode
  symbols occurring in the utf8-file plus the printable ASCII symbols.
```
